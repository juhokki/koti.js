# Project Guidance

- Keep changes simple and focused. Follow the existing conventions and avoid unrelated refactoring.
- Run project commands from the relevant project subfolder, not the repository root. For work across projects, enter each affected subfolder before running its commands.
- Add or update tests for the code you change.
- In each affected subfolder, run the available build, lint and test checks. Fix all failures and rerun those checks before formatting.
- Always run prettier in each affected subfolder as the last step.
- Don't update docs unless requested.
