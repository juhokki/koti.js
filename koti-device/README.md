# Koti-device

Small device with a touch screen that shows the Koti interface. 

## Idea

- Rasperry PI zero W
- Hyperpixel 4.0 square touch display
- Chromium Koti kiosk
- rtl-sdr dongle:
	* Small antenna inside case
- Doorbell:
	* Small usb connected speaker/buzzer
	* Could be triggered from a device action
- Speech recognition:
	* USB connected microphone
	* Recognize keywords to control devices
